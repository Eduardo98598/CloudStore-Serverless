# Recursos Visuales de Categorías (`frontend/assets/categories/`)

Puedes colocar en esta carpeta imágenes o iconos personalizados de tus categorías en caso de que desees conservar tus recursos organizados localmente.

Por defecto, las categorías utilizan iconos de [Bootstrap Icons](https://icons.getbootstrap.com/) (por ejemplo: `bi-laptop`, `bi-cup-hot`, `bi-bag-heart`, `bi-book`, `bi-controller`) configurables en `frontend/js/mock-data.js` o desde el **Panel Admin > Categorías**.
