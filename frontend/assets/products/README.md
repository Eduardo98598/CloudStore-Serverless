# Imágenes de Productos (`frontend/assets/products/`)

Coloca en esta carpeta las fotografías de los productos de tu tienda (formatos recomendados: `.webp`, `.jpg` o `.png`, tamaño sugerido `800x800 px`).

## Cómo usarlas

1. Guarda tu imagen en esta carpeta, por ejemplo:
   `frontend/assets/products/mi-producto-1.webp`
2. En `frontend/js/mock-data.js` (modo demostración) o desde el **Panel Admin > Productos**, escribe la ruta:
   `assets/products/mi-producto-1.webp`
